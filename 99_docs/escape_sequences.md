# C言語 エスケープシーケンス 一覧

文字列（`"..."`）や文字定数（`'...'`）の中で、`\` から始まる特別な文字の書き方。

## 1. 基本のエスケープシーケンス

| 書き方 | 意味 | 文字コード（10進） | 動き・用途 |
|---|---|---|---|
| `\n` | 改行（LF） | 10 | 次の行へ進む |
| `\t` | 水平タブ | 9 | 次のタブ位置まで進む |
| `\r` | 復帰（CR） | 13 | 行の先頭に戻る |
| `\b` | バックスペース | 8 | 1文字左に戻る |
| `\a` | ベル（警告音） | 7 | 端末によっては音が鳴る |
| `\f` | 改ページ | 12 | プリンタ用。端末ではほぼ使わない |
| `\v` | 垂直タブ | 11 | ほぼ使わない |
| `\\` | `\` そのもの | 92 | `\` を表示したいとき |
| `\'` | `'` そのもの | 39 | 文字定数で `'\''` のように使う |
| `\"` | `"` そのもの | 34 | 文字列の中で `"` を表示したいとき |
| `\?` | `?` そのもの | 63 | トライグラフ（`??=` など）と区別するため |
| `\0` | ヌル文字 | 0 | 文字列の終わりを表す |

## 2. 数値で文字を指定する

| 書き方 | 意味 | 例 | 結果 |
|---|---|---|---|
| `\ooo` | 8進数（1〜3桁） | `"\101"` | `A`（65） |
| `\xhh` | 16進数（1桁以上） | `"\x41"` | `A`（65） |

- `\x` の後ろには16進数が必須。`"\x"` だけだとエラーになる。
  - `error: \x used with no following hex digits`
- `\x` は続く16進数（`0-9`, `a-f`, `A-F`）を**すべて**読み込む。`"\x41BC"` は `\x41` + `BC` ではなく `\x41BC` という1つの値になり、範囲外でエラーになる。
  - `error: hex escape sequence out of range`
  - 区切りたいときは文字列を分ける：`"\x41" "BC"` → `ABC`（隣り合った文字列は自動で連結される）
- 8進数は最大3桁までしか読まないので、`"\101BC"` は `ABC` になる。

## 3. 決められていない文字を書いたとき

| 書き方 | コンパイル時（macOS の gcc = clang） | 出力 |
|---|---|---|
| `"[\q]"` | 警告 `unknown escape sequence '\q'` | `[q]`（`\` が消える） |
| `"[\c]"` | 警告 `unknown escape sequence '\c'` | `[c]` |
| `"\e"` | `-pedantic` を付けると警告 `use of non-standard escape character '\e'` | ESC（27）。コンパイラ独自の拡張で、規格外 |

- 一覧にない文字を `\` の後ろに書いたときの動きは、C言語の規格では決まっていない。コンパイラによって結果が違う可能性がある。
- 警告が出たら、書き間違いを疑う。

## 4. 動きの確認例（macOSで実行した結果）

| コード | 出力されるバイト列 | 端末での見え方 |
|---|---|---|
| `printf("ABC\rX\n")` | `A B C \r X \n` | `XBC`（先頭に戻って A を X で上書き） |
| `printf("ABC\bX\n")` | `A B C \b X \n` | `ABX`（1文字戻って C を X で上書き） |
| `printf("A\tB\n")` | `A \t B \n` | `A       B` |
| `printf("%s\|\n", "AB\0CD")` | `A B \|` | `AB\|`（`\0` で文字列が終わるので `CD` は出ない） |
| `printf("[%c]\n", '\'')` | `[ ' ]` | `[']` |

- 端末での見え方は、`\r` や `\b` を端末が解釈した結果。ファイルに出力するとバイトはそのまま残る。
- バイト列は `./a.out | od -c` で確認できる。
