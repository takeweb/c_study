# C言語 演算子 一覧

## 1. 優先順位表

上ほど優先順位が高い（先に計算される）。同じ順位の中では「結合」の向きに計算される。

| 順位 | 演算子 | 意味 | 結合 |
|---|---|---|---|
| 1 | `()` `[]` `->` `.` `後置++` `後置--` | 関数呼び出し、配列の添字、メンバ参照、後置インクリメント/デクリメント | 左→右 |
| 2 | `前置++` `前置--` `+` `-` `!` `~` `*` `&` `(型)` `sizeof` | 単項演算子（符号、否定、ビット反転、間接参照、アドレス、キャスト、サイズ） | 右→左 |
| 3 | `*` `/` `%` | 乗算、除算、剰余 | 左→右 |
| 4 | `+` `-` | 加算、減算 | 左→右 |
| 5 | `<<` `>>` | ビットシフト | 左→右 |
| 6 | `<` `<=` `>` `>=` | 大小比較 | 左→右 |
| 7 | `==` `!=` | 等しい、等しくない | 左→右 |
| 8 | `&` | ビットAND | 左→右 |
| 9 | `^` | ビットXOR | 左→右 |
| 10 | `\|` | ビットOR | 左→右 |
| 11 | `&&` | 論理AND | 左→右 |
| 12 | `\|\|` | 論理OR | 左→右 |
| 13 | `? :` | 条件演算子（三項演算子） | 右→左 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=` | 代入 | 右→左 |
| 15 | `,` | コンマ演算子 | 左→右 |

## 2. 種類別

### 算術演算子

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` | 加算 | `7 + 2` | `9` |
| `-` | 減算 | `7 - 2` | `5` |
| `*` | 乗算 | `7 * 2` | `14` |
| `/` | 除算 | `7 / 2` | `3`（整数同士は小数点以下切り捨て） |
| `%` | 剰余（余り） | `7 % 2` | `1` |

- 負の数の除算は0の方向に切り捨てる：`-7 / 2` → `-3`、`-7 % 2` → `-1`
- `%` は整数専用。浮動小数点の余りは `<math.h>` の `fmod` を使う。

### インクリメント・デクリメント

| 演算子 | 意味 | 例（`i = 5` のとき） | 式の値 | 実行後の `i` |
|---|---|---|---|---|
| `++i` | 先に1増やしてから使う | `++i + 1` | `7` | `6` |
| `i++` | 使ってから1増やす | `i++ + 1` | `6` | `6` |
| `--i` | 先に1減らしてから使う | `--i` | `4` | `4` |
| `i--` | 使ってから1減らす | `i--` | `5` | `4` |

### 比較演算子（結果は 1 か 0）

| 演算子 | 意味 |
|---|---|
| `==` | 等しい |
| `!=` | 等しくない |
| `<` / `<=` | より小さい / 以下 |
| `>` / `>=` | より大きい / 以上 |

- `=`（代入）と `==`（比較）の書き間違いに注意。

### 論理演算子（結果は 1 か 0）

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `&&` | かつ（AND） | `5 && 0` | `0` |
| `\|\|` | または（OR） | `5 \|\| 0` | `1` |
| `!` | 否定（NOT） | `!5` | `0` |

- 0 以外は「真」、0 は「偽」として扱われる。
- `&&` は左が偽、`||` は左が真なら、右側は計算しない（短絡評価）。

### ビット演算子

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `&` | AND | `6 & 3`（`110 & 011`） | `2`（`010`） |
| `\|` | OR | `6 \| 3`（`110 \| 011`） | `7`（`111`） |
| `^` | XOR | `6 ^ 3`（`110 ^ 011`） | `5`（`101`） |
| `~` | ビット反転 | `~0` | `-1` |
| `<<` | 左シフト | `1 << 2` | `4` |
| `>>` | 右シフト | `-8 >> 1` | `-4`（この環境での結果） |

- 負の数の右シフトの結果は、規格では環境ごとに決めてよいことになっている。

### 代入演算子

| 演算子 | 意味 | 同じ意味の書き方 |
|---|---|---|
| `=` | 代入 | — |
| `+=` | 足して代入 | `a = a + b` |
| `-=` | 引いて代入 | `a = a - b` |
| `*=` | 掛けて代入 | `a = a * b` |
| `/=` | 割って代入 | `a = a / b` |
| `%=` | 余りを代入 | `a = a % b` |
| `<<=` / `>>=` | シフトして代入 | `a = a << b` / `a = a >> b` |
| `&=` / `\|=` / `^=` | ビット演算して代入 | `a = a & b` など |

### その他

| 演算子 | 意味 | 例 |
|---|---|---|
| `? :` | 条件演算子 | `a > b ? a : b`（大きい方） |
| `,` | 左から順に計算し、右端の値になる | `(a = 1, b = 2, a + b)` → `3` |
| `sizeof` | 型や変数のバイト数 | `sizeof(int)` → `4` |
| `(型)` | キャスト（型変換） | `(int)3.7` → `3` |
| `&` | アドレスを取る | `&x` |
| `*` | ポインタの指す先 | `*p` |
| `->` | ポインタからメンバ参照 | `p->x`（`(*p).x` と同じ） |
| `.` | 構造体のメンバ参照 | `s.x` |
| `[]` | 配列の添字 | `a[0]` |

## 3. 優先順位で間違えやすい例（macOSで実行した結果）

| 式 | 実際の計算 | 結果（`a = 6`） | コンパイラの警告 |
|---|---|---|---|
| `a & 2 == 2` | `a & (2 == 2)` | `0` | `& has lower precedence than ==` |
| `(a & 2) == 2` | 意図どおり | `1` | なし |
| `1 << 1 + 1` | `1 << (1 + 1)` | `4` | `operator '<<' has lower precedence than '+'` |
| `*p++` | `*(p++)`：値を取ってから `p` を進める | 1つ目の要素 | なし |

- 迷ったらカッコを付ける。`-Wall` を付けると、こうした書き方を警告してくれる。
